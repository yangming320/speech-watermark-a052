# M6 补充机制分析协议

在主 M6 尚处于 train/validation 准备、没有扩展 test 评分时固定以下补充控制。主 E06～E09 的训练、阈值和数据不改变，另作有独立来源/配置/哈希的派生分析。

1. 共同有效帧控制：对每条 test 原语句取四码率×正负标签共八份接收文件的 VAD 完整窗交集，所有码率、标签、检测器使用相同原始帧索引和分组。用已审计逐帧预测重算 EER，另与直接模型推理抽样核对。该控制利用成对标签和所有通道，不是可部署盲检测流程；报告交集后保留数量，不能冒充完整测试覆盖。
2. 按说话人重采样：只取每条语句首个 30 帧组，在固定验证阈值下计算混合模型与单码率模型的误差差异。每次整体重采样 40 位 test 说话人，保留其全部语句、正负配对与三个种子；1000 次固定种子 20261018 bootstrap，输出均值和 2.5/97.5 百分位。统计对象是首组固定阈值平衡错误率差，不是主表全部帧组 EER 的置信区间。零差/跨零区间如实保留。
3. 挑选失败案例只用于说明：从保存分数按固定排序选首个假阳性、假阴性和改进/退化案例，保留 UID、阈值来源和音频。不能用这些例子调回强度、模型轮数、阈值或源样本。

这些分析旨在区分码率影响中的 VAD 组成和阈值迁移，并显示说话人层面的不确定性。相关观察不声称已经确定全部因果机制。
