# M6 扩展实验协议 v1

M5 完成并冻结后开展 E06～E09。沿用 568 句、74 人、train/validation/test=288/80/200 的 LibriSpeech 固定替代子集、相同密钥、共同增益、特征、A/B 架构及第 25 轮策略。三个种子为 2026/2027/2028。M5 测试集已用于主实验，本轮称为同一冻结测试集上的探索；不称为另一份从未触及的确认集。不依据扩展测试反馈改变强度、轮数、码率或分数方向。

## E07：固定 8 kb/s 模型跨码率

逐字节复制 M5 的 C3 第 25 轮六个主权重和 8 kb/s 接收文件。SS 3 dB，先降至 8 kHz，再分别经 Opus 6、8、12、16 kb/s 硬 CBR；其余编码选项与 M2 相同。保存真实压缩流、编码输入、解码 WAV、FFmpeg 命令及 Ogg/TOC 检查。20 ms 包的实际字节数应为 15、20、30、40。相关/A/B 共享每文件 VAD 和分组，聚合 1、10、30 个有效帧。

主固定阈值始终采用 M5 的 validation/C3/8 kb/s 阈值，不能针对各测试码率重校准。另保存各码率 validation 阈值的诊断结果，以区分区分能力变化和阈值漂移；诊断不得替换主固定阈值表。分别报告正负 VAD 覆盖、谱/分数均值、EER、每句首组 EER、固定 FAR/FRR。

## E08：混合码率训练

复用原 288 条训练源语音，生成四种码率的相同标签派生物。按每个标签从各码率等额选训练帧，总量严格等于 M5/C3 对应标签的训练帧数；余数以固定码率顺序分配，每码率相差至多 1 帧。不重复抽帧，保存来源文件和有效帧索引，固定抽样种子 20261018。四码率的数据复制不能导致四倍训练预算。

A/B 各三个种子，共六个新模型；batch=1024、25 轮、RMSprop 与 M5 完全相同。样本总数、每轮优化步数、模型初始化种子均与单码率对照匹配。训练期间的 validation 诊断使用原 8 kb/s validation；不用它挑轮。最终校准使用四种码率的 validation 帧组混合，每检测器/种子/聚合长度只有一个混合阈值，原样应用到全部测试码率；保留分码率诊断阈值。混合验证中的四份派生物来自同一批 80 句，不能当成 320 句独立语音。

## E06：LPC 与深度检测组合

验证集已选定的音质配对固定 SS 2 dB / LPC 6 dB，不能按 M6 测试分数改选。分别在降采样至 8 kHz、8 kHz→Opus 8 kb/s 下，训练兼容的 SS/LPC A/B 三种子模型，新增 24 个设置；不能把仅在 SS 训练的 M5 权重冒充 LPC 训练模型。

为控制训练预算，每条训练语句/标签在上述四个接收条件中取最小有效帧数，各条件在自身有效帧内固定种子无放回抽取相同数量，保留时间顺序和索引。因此四条件训练源、逐文件/标签帧数、总帧数和优化步数完全一致。validation 与 test 使用全部有效帧，不裁成训练预算。两种方法的通道前 PESQ 直接引用 M5 的同一验证/测试强度实测；接收音质另记录，只做验证、测试，不据此选强度。

## E09：已知起点偏移分析

对同一 R8 接收 WAV 在起点裁去 0、2.5、5、10、15、20 ms 的样本，重提特征/VAD，比较相关、固定 8 kb/s 模型与混合码率模型。只从起点裁去实际样本，不补零、不重新编码、不用原音频做相关对齐。记录裁剪样本数、剩余长度和覆盖率。

固定阈值继承未偏移条件；报告 EER 与固定 FAR/FRR。裁剪造成观测长度略短，报告覆盖，不将全部差异归因于相位。0 ms 必须与 E07/R8 逐组一致。该分析不实现未知偏移搜索，不按所有偏移最高分判决；任意上传仍只报分数。

## 冻结、核验、归档

先冻结本协议与配置、M5 依赖哈希；准备 train/validation，生成训练抽样清单，训练 30 个新模型并完成验证校准；保存包含 36 个主权重及阈值哈希的门文件后，才生成扩展 test 通道并评分。零强度对照在每分区固定十条、四码率下逐类生成并验证 EER=50%。

原语料及 M5 冻结文件哈希核验；每个新增接收 WAV 重提特征，所有码流检查实际码率和长度；重新加载全部 36 个权重、核验逐帧 logits 缓存和全部聚合 CSV，再重算 EER、三种子均值/样本标准差、阈值和 FAR/FRR。每个训练族（混合及四组合条件）种子 2026 的 A/B 共十设置完整重训；其余种子只重推理。接收 PESQ 重跑分区×条件×标签各一个固定样例。独立 CLI 需覆盖全部新模型，恢复检查使用当前依赖，不声称已验证 Linux/云端。

保留失败尝试，不覆盖既有运行。M5 标签和证据不改写。新增本地附注标签与完整 ZIP/bundle/SHA 校验，最后交付本地演示、部署准备和汇报材料；云端实际启动、外部访问和 GitHub 发布另列待办。
